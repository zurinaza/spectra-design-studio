# SPECTRA Design Studio

An interactive, flow-first learning application for **ECH3127: Physical Separation Process**, Universiti Putra Malaysia.

Developed by **Prof. Dr. Zurina Zainal Abidin**.

## Learning workflow

1. Scope the design problem.
2. Prepare and validate the BFD/PFD: order separation units and accessories, select the target equipment, and label every material stream.
3. Enter stream specifications and traceable design evidence.
4. Check degrees of freedom, solve material balances, estimate duty, and size the target equipment.
5. Test the preliminary design using transparent feasibility checks.
6. Review sensitivity, CAPEX, OPEX, ROI, payback, NPV, operability, and risk.
7. Defend the recommendation and export the design portfolio.

Design evidence can be provided by typing/pasting information, entering a URL or DOI, or embedding a file up to 1 MB. Missing conditions, units, references or applicability are flagged for revision. All stages remain open so students can preview later work while incomplete items stay visible.

The evidence stage provides separate collection spaces for project requirements, properties, design methods, equilibrium/kinetic data, equipment limits, cost data and assumptions. These spaces are labelled Core, As needed, Recommended, Later stage or Optional; students may continue with visible flags when evidence is incomplete.

The simulator is an educational preliminary-design tool. It does not replace a validated thermodynamic package, Aspen Plus, detailed mechanical design, or vendor verification.

## Publish with GitHub Pages

Upload `index.html`, `app.js`, `styles.css`, this `README.md`, and the complete `assets` folder to the root of the repository.

Then open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and save. GitHub will show the public site address after deployment.
